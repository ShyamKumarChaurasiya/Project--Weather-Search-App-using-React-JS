# Project--Weather-Search-App-using-React-JS
A weather search application built using React.js, Material UI (MUI), and REST API integration to fetch and display real-time weather information for searched cities. Features dynamic weather images and icons based on temperature, interactive search functionality, and a clean, user-friendly interface.
